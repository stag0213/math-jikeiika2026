# 線分PQが通過してできる図形 S の可視化

空間内を動く線分 PQ が通過してできる図形 S を、3Dで観察できるWebアプリです。
Three.js を使っていて、HTMLファイル1つで動きます。

## 問題設定

空間内に次の5点があります。

| 点 | 座標 |
|----|------|
| A | (2, 0, 0) |
| B | (0, 2, 0) |
| C | (0, 0, 2) |
| D | (1, 1, 0) |
| E | (0, 0, 1) |

線分 OA 上に点 P(p, 0, 0)(0 ≤ p ≤ 2)をとります。平面 PDE と直線 BC の交点を Q とします。
p を動かしたときに線分 PQ が通過してできる図形 S を可視化します。
さらに、平面 x = 2y と S との交わりも表示します。

## 数学的な整理

### 平面 PDE

$\vec{PD}=(1-p,\ 1,\ 0)$、$\vec{PE}=(-p,\ 0,\ 1)$ の外積をとると、法線ベクトルは $\vec n=(1,\ p-1,\ p)$ です。したがって平面 PDE の式は次のようになります。

$$(x-p)+(p-1)y+pz=0$$

### 点 Q

直線 BC を $(0,\ 2-2s,\ 2s)$ と表して平面の式に代入すると、$s = 1 - \frac{p}{2}$ となります。よって

$$Q(0,\ p,\ 2-p)$$

p = 0 のとき Q = C、p = 2 のとき Q = B なので、Q は線分 CB 全体を動きます。

### 図形 S

線分 PQ 上の点は、次のように表せます。

$$(p(1-t),\ pt,\ (2-p)t)\qquad (0\le p\le 2,\ 0\le t\le 1)$$

$x+y=p$、$y=pt$ から p と t を消去すると、S は次の曲面の一部であることがわかります。

$$z(x+y)=y(2-x-y)\qquad (x\ge 0,\ y\ge 0,\ x+y\le 2)$$

S は直線の集まりでできた曲面(線織面)です。

### 平面 x = 2y との交わり

線分 PQ 上の点を $x=2y$ に代入すると、$p(1-t)=2pt$ より $t=\frac13$ です。線分 PQ と平面の交点は

$$R\left(\tfrac{2p}{3},\ \tfrac{p}{3},\ \tfrac{2-p}{3}\right)$$

となります。また、p = 0 のときの線分 PQ は線分 OC で、これは平面 x = 2y に含まれます。
したがって、平面 x = 2y による S の切り口は次の2本の線分です。

- 線分 OC
- 点 $(0,\ 0,\ \frac23)$ と点 $(\frac43,\ \frac23,\ 0)$ を結ぶ線分

## 使い方

1. `index.html` を保存します。
2. インターネットに接続した状態で、ブラウザで開きます(Three.js を CDN から読み込むため)。

ブラウザによっては、ローカルファイルからの ES Modules の読み込みが制限されることがあります。
うまく表示されない場合は、簡易サーバーを立ち上げて開いてください。

```bash
# Python 3 の場合
python -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

## 機能

| 機能 | 内容 |
|------|------|
| スライダー | p を 0〜2 の範囲で動かせます |
| 再生 / 停止 | p を自動で往復させるアニメーションです |
| 視点リセット | カメラを最初の位置に戻します |
| 座標表示 | P・Q・R の座標をリアルタイムで表示します |
| 平面 PDE | オレンジの半透明の面と、三角形 PDE の辺(破線)を表示します |
| 図形 S | 0 から現在の p までに通過した部分を色付きの曲面で表示します(色は p に応じて変化) |
| S全体 | S 全体を薄いワイヤーフレームで表示します |
| 母線 | 通過した線分 PQ を一定間隔で描きます |
| 四面体 OABC | 補助線として破線で表示します |
| 平面 x = 2y | 緑の半透明の面、四面体の切り口、S との交わり(太線)、交点 R を表示します |

各要素は、パネルのチェックボックスで表示 / 非表示を切り替えられます。

### マウス操作

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 回転 |
| ホイール | 拡大・縮小 |
| 右ドラッグ | 平行移動 |

## 色の凡例

| 色 | 対象 |
|----|------|
| 赤 | 点 P、線分 PQ |
| 青 | 点 Q、直線 BC |
| 青緑 | 定点 D、E |
| オレンジ | 平面 PDE |
| 緑 | 平面 x = 2y、S との交わり、点 R |
| 青→黄(グラデーション) | 図形 S(p の値に対応) |

## 使用技術

- [Three.js](https://threejs.org/) r160(CDN: unpkg)
  - `OrbitControls`:マウスによる視点操作
  - `CSS2DRenderer`:点や軸のラベル表示
- ES Modules + Import Maps

## 動作環境

Import Maps に対応した最近のブラウザ(Chrome、Edge、Firefox、Safari の最新版)で動作します。
